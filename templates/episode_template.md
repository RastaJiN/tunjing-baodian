# 吞鲸工作室 · 标准单集工业化生产模板 (EPxxx Universal Template)
> 本模板只定义**工业化结构槽位与时间呼吸骨架**，不绑定任何固定题材、场景、道具或固定桥段。
> 创作时请根据当前剧集的真实世界观、场地与人物关系填入对应变量。

## 头部基本盘 (Metadata)
- **剧名**：`{{ DRAMA_NAME }}`
- **集数**：`EP{{ EP_NUM }}`
- **目标总时长**：`{{ TOTAL_SEC }}` 秒 (如 120s 或 300s；按 2~6s/镜自动拆解为独立短镜)
- **当前场景 (`--scene`)**：`{{ SCENE_NAME }}` *(传入真实场地名，如：温泉汤池 / 游艇座舱 / 落地窗书房 / 客厅沙发 / 暴雨车内 / 卧室大床；引擎将自动适配承托面与环境底噪)*

## 一、三幕式剧本结构框架 (The 3-Act Dramatic Skeleton)

### [第一幕：张力建立与欲望导火索] (约占全片 25% 时长)
- **戏剧任务**：交代当前场域氛围、两人此刻的戏剧关系张力，并用一个核心触发点（感官接触 / 情感对峙 / 规则困境 / 关键信物）点燃导火索。
- **台词对白**：
  - 角色 A：`<d>[Chinese] {{ LINE_ACT1_A }}</d>`
  - 角色 B：`<d>[Chinese] {{ LINE_ACT1_B }}</d>`
- **第一幕收束点**：双方心理距离或物理距离被强行拉近，情绪推至临界点。

### [第二幕：防线瓦解、前戏升温与中段势能转折] (约占全片 30% 时长)
- **戏剧任务**：进入亲密前戏试探，并在中段触发本集选定的 **`{{ MIDPOINT_ARCHETYPE }}`（势能转折）**，打破单一线性节奏，将情绪与生理张力推向更高维度。
- **物理动作**：调用前戏与口爱姿势链（如 `{{ FOREPLAY_POSES }}`），包含 1.5s 生理阻断微距特写。
- **台词对白**：
  - `<d>[Chinese] {{ LINE_ACT2 }}</d>`

### [第三幕：多体位主戏爆发与终局余韵/钩子] (约占全片 45% 时长)
- **第一阶段体位**：调用 `{{ MAIN_POSE_A }}`，配合低机位腰胯特写（交合特写 1 · 结合部微距）；
- **第二阶段换体位**：通过物理换位配方过渡至 `{{ MAIN_POSE_B }}`（及 `{{ MAIN_POSE_C }}`），包含深层抽送微距（交合特写 2）与绝顶微距（交合特写 3）；
- **第三阶段绝顶清算**：调用 `{{ FINISH_POSE }}` 完成生理释放与情绪平息；
- **集尾收束 (Hook)**：贴合本集主线剧情留下一记余韵或悬念钩子（人物关系的新变化、未解的秘密或下一场的伏笔）。

## 二、一键拆镜与落盘命令

剧本定稿后，直接将本集参数喂给拆镜引擎，自动生成适配 `{{ SCENE_NAME }}` 承托面的 `分镜.md` + `视频提示词.md` + `批量任务.json`：

```bash
python scripts/tunjing_scene.py \
  --chain "{{ POSE_CHAIN }}" \
  --total {{ TOTAL_SEC }} \
  --scene "{{ SCENE_NAME }}" \
  --lines "{{ KEY_SHORT_LINE }}" \
  --idea "{{ EPISODE_BRIEF }}" \
  --out-dir "<项目集目录>"
```
