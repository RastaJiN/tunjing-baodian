# 吞鲸宝典 · 在制接盘与断点修复规范 (Hot-Takeover & Patching Protocol)
> 专为接手半截工程、剧本缺斤少两、分镜脱节的烂摊子项目量身打造。
> 唯一铁律：保护已有合格资产，逆向推导状态继承，局部细胞级置换，严禁盲目开跑！

---

## 一、接盘第一步：基线资产与断点盘点 (The Inventory Audit)

接手任何在制项目，严禁直接启动生成！必须先执行四项排查并生成《断点清单》：

1. **已认可素材保护 (Protected Shots)**：
   - 扫描已有 `SHOT-*.mp4`，凡是已验收合格的镜头，记录其镜号、时长、画面最后一帧的服装/体位状态；
   - 这些镜头在后续驱动中强制打上 `SKIP_RENDER` 标记，绝对不重渲浪费算力！
2. **断点与空洞扫描 (Gaps & Voids)**：
   - 剧本有台词但分镜漏掉的镜头；
   - 动作跳步（如上一镜穿戴整齐，下一镜突然全裸交合，中间缺少衣物剥离与推倒过程）；
   - 空间瞬移（上一镜在客厅，下一镜无过继直接在浴室）。

## 一之一、宝典热接盘时的【智能诊断与修改意见报告】(The Audit & Prescription Report)

当在制项目引入宝典时，宝典**绝对不当哑巴，也不瞎跑！** 必须首先出具一份**《宝典热接盘诊断与微创修改方案》**，呈现给监制审阅：

```markdown
# 吞鲸宝典 · 在制剧集热接盘诊断报告
- 剧目：{{ DRAMA_NAME }} · EP{{ EP_NUM }}
- 接盘状态：在制接盘 (已出片 N 镜 / 待出片 M 镜)

### 一、当前剧本与分镜痛点诊断：
1. 【节奏短板】：文戏段落存在 N 处无戏剧因果的对坐闲聊（建议引入道具证据下套）；
2. 【高能戏缺项】：未达到宝典刚性标准（检测到缺口交近景 / 仅有 1 个体位未换体位 / 交合微距不足 3 次）；
3. 【音画脱节风险】：检测到 SHOT-xx 台词超长（时长仅 3s，台词需要 7s，必导致嘴瓢）；
4. 【OS 对口型隐患】：检测到独白镜头正面露脸未加嘴部物理占位锁。

### 二、宝典微创修改建议（不推翻已合格镜头）：
- [建议 1 · 保护项]：已合格出片的 SHOT-01~05 严格保持原样，锁定退出状态；
- [建议 2 · 废镜置换]：将旧分镜中平淡发呆的 SHOT-08，原地置换为【1.5s 指节抓白阻断微距】；
- [建议 3 · 动作补齐]：在 SHOT-10 与 SHOT-11 之间插入【换位转场桥 (missionary ➔ cowgirl ➔ doggy)】与【结合部深顶咬合微距】，补足高潮张力；
- [建议 4 · 台词精简]：将 SHOT-03 超长台词精简至 11 字以内，完美咬合物理秒数。
```
**监制确认该修改意见后，宝典才启动差量重排与增量渲染！**

## 二、接盘第二步：逆向物理状态继承 (Reverse State Stitching)

修补缺失的断点镜头时，必须严格执行“向上向下双向对齐”：

```
[前序已知合格镜头的 Exit State]
  - 服饰：继承上一镜末尾的真实着装状态（如领口微敞 / 衣摆半褪）
  - 空间：继承上一镜的真实场地承托面与光源方向
  - 关系：继承上一镜末尾两人的相对站位与姿态
         ↓ (强制锁定为断点补齐镜头的唯一 Entry State！)
【吞鲸补齐镜头 (The Patch Shot)】
  - 动作：顺着上一镜的站位自然推进着装变化或转入吞鲸引擎对应体位（通过 with_scene_surface 适配当前场地）
  - 衔接：绝不可凭空变出别的衣服或瞬移到无关家具（如在浴室里突然出现床单），必须交代物理因果！
         ↓
[后续已知镜头的 Entry State]
```

## 三、接盘第三步：局部细胞级重构 (In-Place Transmutation)

如果旧项目剧情平淡、缺乏高潮特写，**绝不增加总集总时长，只做镜位功能置换**：

1. **废镜置换法**：
   - 找到旧分镜里无信息量的中景、发呆镜、重复的对视镜；
   - 原地改写为：**【1.5s 生理阻断微距】（抓桌沿抓白/咬破下唇）** 或 **【结合部深层咬合微距 (POS)】**；
   - 保持该镜头的时长/帧数不变，仅替换视觉承载，瞬间拉升全片带电感。
2. **台词超长外科手术**：
   - 旧分镜如果短镜头塞长台词，严禁直接送模（必导致嘴瓢或断音）；
   - 立即执行台词精简：保留核心带刀词汇，砍掉多余助词与连词，严格满足 $\text{字数}/3.0 + 1.0\text{s} \le \text{原镜时长}$。
3. **体位与深喉缺项补位**：
   - 若旧分镜缺少口交或换体位，在断点补齐区间强制插入一组 **深喉近景 ➔ 体位转换过继镜**，补齐吞鲸高能戏刚性契约。

---

## 四、接盘第四步：增量差量渲染与时间线缝合 (Incremental Dispatch)

1. **差量生成**：
   - 驱动脚本只把状态标记为 `NEEDS_RENDER` 的断点补齐镜头送入 ComfyUI 队列；
2. **切点微调**：
   - 渲染落盘后，通过剪映草稿工程或 FFmpeg 脚本，利用 L-Cut/J-Cut 吞吐 0.1~0.3 秒的帧长余量，将新补镜头与旧合格镜头无缝咬合！
